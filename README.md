# gyomu-app-kobo-estimate

## プラン別見積り

- 最初に「かんたんアプリプラン」「しっかりアプリプラン」を選択します。
- 既存の見積・マスターは「かんたんアプリプラン」として引き継がれます。初回起動時に「しっかりアプリプラン」用のマスターを複製します。
- 「しっかりアプリプラン」は初期状態では非公開です。管理画面の「マスター管理」でプランを切り替え、端末単価・パック内容・追加機能を設定してから公開してください。
- 標準の「基本パック」「運用パック」「カスタムパック」は画面遷移に使用するため、名前を固定しています。内容・金額はプランごとに編集できます。
- 管理画面の見積り履歴ではプラン、パック、日付、ID等で検索できます。プラン未選択で離脱したアクセスは「未選択」と表示されます。
- カスタムパックの「画面表示項目追加」は、管理画面の「マスター管理」→「追加機能」の該当行から端末別単価を展開できます。プランごとに共通単価と端末別単価を一度に更新できます。端末別単価を空欄にすると共通単価を使い、0円を入力すると0円を適用します。

既存のPostgreSQLへ適用する際は、事前にDBのバックアップを取得してください。アプリ起動時に不足カラムの追加とプラン別マスターの初期複製が行われます。

## サーバー保守の月額オプション

- しっかりプランでは、全パックの見積り結果画面で「サーバー保守」を選べます。初期費用とは別に月額を表示し、PDF・問い合わせ・メール・LINE WORKS・管理画面にも引き継ぎます。
- 金額は、しっかりプランの追加機能マスター「サーバー保守/月」の単価を使用します。有効なマスターがない場合、新規選択欄は表示されません。この機能名は固定してください。数量指定は使用せず、カスタム機能一覧には表示しません。
- 選択時の月額単価を保存します。マスター更新後も保存済み見積りの金額は変わりません。問い合わせ送信後は保守選択を変更できません。
- 新規見積りでは保守を選択済みにします。一度外した見積りを再計算・再表示しても選択は戻しません。
- 初回適用時、既存のしっかりプランの見積項目に「サーバー保守/月」があれば、保存済みの項目金額を初期費用から月額欄へ移します。再起動時に重複して移すことはありません。
